PROJECT NOTES

Design overview

Overview

StealthComm is a proof-of-concept handheld communication device built around a Raspberry Pi. It converts Morse-code button presses into readable terminal messages and represents incoming terminal messages as LED flashes.

How it works

Python handles Morse-code translation and GPIO input/output. Short and long button presses represent dots and dashes, while timed gaps distinguish letters and words. An SSH connection links the Raspberry Pi and a remote computer.

Design and development

I prototyped the physical interface using a push-button, LED, breadboard, and Raspberry Pi; implemented timing-based input recognition and Morse-code translation in Python; then documented setup, operation, and hardware iterations.

Next steps

The current version demonstrates the concept. Potential refinements include reducing the enclosure size, simplifying the wiring, and using a smaller controller.
